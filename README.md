# Module 9 Tailwind Redesign

This is my Module 8 Student Directory project redesigned with Tailwind CSS.

## What it has
- Tailwind CSS with the Vite plugin
- Responsive layout (1 column on mobile, 2 on tablet, 3 on desktop)
- Dark mode toggle
- Responsive navbar with a menu button on mobile
- Card layout for the users
- Hover effects and smooth transitions

## Reusable components
- Button.tsx
- Card.tsx
- Navbar.tsx
- DarkModeToggle.tsx

## Colors
- Primary: blue 600
- Secondary: slate 700
- Accent: emerald 500

## How to run
```
npm install
npm run dev
```
